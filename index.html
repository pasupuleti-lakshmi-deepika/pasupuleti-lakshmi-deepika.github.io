Enterprise Master Data Integration Platform

Hands-on Project

The problem: customer, product, and supplier data lives in separate datasets that don't line up — different sources, no single trusted view. This project consolidated all three into one warehouse with quality checks, so downstream reporting works from consistent master data.

Architecture

Amazon S3 · raw zone→ AWS Glue · ingestion→ Python · transformations→ Snowflake · warehouse→ dbt · staging / dim / fact→ SQL validation checks

What I built

  • ETL/ELT pipelines with AWS Glue and Python consolidating customer, product, and supplier datasets into Snowflake.
  • Raw-zone landing on Amazon S3 as the entry point for source data before ingestion.
  • Incremental dbt models organized into staging, dimension, and fact layers using dimensional modeling.
  • SQL validation checks to enforce data quality across the consolidated datasets.
